# AE Презентация — инструкции для ИИ

Перед любой работой (над приложением или над презентацией для автора) прочитай **docs/AE_PRESENTATION_GUIDE.md** — там предпочтения автора, жёсткие правила по фактам, фото и дизайну и журнал прошлых ошибок. После работы допиши в журнал новые ошибки и решения.

## Приложение
- Всё приложение — один файл `index.html` (PWA, GitHub Pages: https://ayansagyngali.github.io/ae-prezentaciya/). Сборки нет.
- Текст — Google Gemini по ключу пользователя (`gemini()`), фото — Wikimedia Commons (`AEP_PHOTOS`, `AEP_FIND_PHOTO`).
- Правила для модели: `RULES` (в конце — «ЖЁСТКИЕ ПРАВИЛА»), `LAYOUT_SPEC`, `CHAT_RULES` (чат-правка).
- Редактор: `editor()`; чат-правка: `chatEdit(deck, msg, cur)` — операции edit / replace / insert / delete / move / photo / title, каждая проверяется в коде.
- CSS слайдов есть в двух местах: в `<style>` страницы и в строке `SLIDES_CSS` (для экспорта). Новые правила слайдов добавляй в `EXTRA_CSS` — она подключается и там, и там.

## Проверка перед коммитом
- Скрипты парсятся (`node` + `vm.Script` по каждому `<script>`).
- Открыть страницу локально (`python3 -m http.server`), отрисовать слайд через `AER.renderSlide`, проверить чат-правку с заглушкой `cap.sample`.
- Ответы автору — по-русски, коротко.
