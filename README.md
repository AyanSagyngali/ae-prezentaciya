# AE Презентация — iPhone

Презентации на русском и қазақша: 30 стилей, свой вид, текст пишет Google Gemini по вашему ключу (хранится только в телефоне), фото из Wikimedia Commons.

Установка: откройте https://ayansagyngali.github.io/ae-prezentaciya/ в Safari → «Поделиться» → «На экран Домой».

Шрифты: Google Fonts (OFL). Иконки: Lucide (ISC). Фото: Wikimedia Commons, автор и лицензия на каждом фото.
